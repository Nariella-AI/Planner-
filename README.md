# Planner Pro

Небольшой веб-проект: приветственный лендинг + функциональный планер идей.

## Возможности

- Добавление идеи с текстом и датой плана.
- Дата создания каждой записи.
- Отметка идеи как выполненной.
- Фильтрация: все / активные / выполненные.
- Режимы просмотра: список и календарь.
- Редактирование и удаление идеи.
- Кнопка "Очистить всё".
- Сохранение данных и состояния интерфейса в `localStorage`.

## Запуск

Проект статический, поэтому достаточно открыть файл `index.html` в браузере.

Можно и через локальный сервер (необязательно):

1. Откройте папку проекта в терминале.
2. Запустите любой простой сервер, например:
   - `python -m http.server 8000`
3. Откройте `http://localhost:8000`.

## Где хранятся данные

- Идеи: ключ `planner_pro_calendar_items`
- Состояние интерфейса (фильтр/вид/месяц): ключ `planner_pro_ui`

Данные хранятся только локально в браузере на вашем устройстве.
